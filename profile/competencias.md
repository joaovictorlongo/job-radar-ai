# Competências Técnicas e Conhecimentos

## Linguagens e Runtimes
- **TypeScript:** Nível avançado/sênior. Tipagem estrita (`strict: true`, `noUncheckedIndexedAccess`, zero `any`), generics avançados, mapped types, type guards e asserções customizadas.
- **JavaScript (ES2022+):** Domínio completo de event loop, async/await, closures, prototypes, iterators e proxies.
- **Node.js (v20/v22):** Desenvolvimento de microsserviços, streams, buffers, clustering e integração com ecossistema npm/pnpm.
- **Bun:** Conhecimento prático de runtime alternativo, testes nativos e bundler.
- **SQL:** Consultas complexas, joins analíticos, CTEs (Common Table Expressions), window functions, índices B-Tree, GIN e HNSW (pgvector).
- **Python:** Básico/intermediário para automações, scripts de machine learning, CLI e testes com pytest.
- **Delphi / Pascal:** ~10 anos de experiência histórica em lógica de programação e sistemas corporativos.

## Frameworks e Bibliotecas Backend
- **NestJS:** Arquitetura modular, injeção de dependências, guards, interceptors, pipes, custom decorators, módulos CQRS e microsserviços.
- **Express / Fastify / Elysia:** Criação de servidores HTTP leves e rápidos com middlewares de validação, segurança e observabilidade.
- **GraphQL:** Criação de schemas com code-first / schema-first, resolvers com batching (Dataloader) e tratamento de N+1.
- **Zod:** Validação estrita de contratos de entrada, saída, schemas dinâmicos e parsing de structured output de LLMs.
- **Drizzle ORM / Prisma:** Definição de schemas type-safe e migrations versionadas.

## Frontend e Web
- **Angular (v14 a v20+):** Standalone components, signals, OnPush change detection, RxJS, reactive forms, interceptors HTTP e roteamento avançado.
- **Astro:** Arquitetura em ilhas (islands), Server-Side Rendering (SSR) e geração estática para sites de alta performance.
- **Next.js / React:** Conhecimento conceitual e prático em React moderno (hooks, context, suspense) e Next.js App Router (Server Components, Client Components, Server Actions).

## Inteligência Artificial e LLMs
- **Structured Outputs:** Contratos estruturados via JSON Schema nativo com Zod e validação determinística pós-resposta.
- **Grounding e Mitigação de Alucinação:** Validação de citações literais (`evidence_span`), verificabilidade de fontes e gates duros para impedir extrapolações ou dados inventados (ex.: salário).
- **Embeddings e Busca Vetorial:** pgvector com indexação HNSW, cálculo de distância de cosseno, chunking semântico de documentos e pipelines de RAG.
- **Avaliação Sistemática (Evals):** Harness de testes com dataset ouro rotulado, concordância inter-anotadores (Cohen's $\kappa$), precisão, recall, F1-score (micro e macro) e tracking de custo/latência.
- **Formação em IA:** Bacharelado em Inteligência Artificial em andamento na Univesp (2026–2030).

## Banco de Dados e Cloud
- **PostgreSQL:** Modelagem relacional, transações ACID, isolamento de concorrência, extension pgvector, constraints avançadas e tuning de performance.
- **SQL Server / MySQL / Firebird:** Experiência sólida de mais de 8 anos em bancos relacionais corporativos e rotinas transacionais.
- **Redis:** Fila BullMQ, rate limiting por chave/domínio, pub/sub e caching.
- **Docker / Docker Compose:** Multi-stage builds, isolamento de containers e orquestração de serviços de desenvolvimento e CI.
- **AWS:** S3, SQS, ECS, RDS, IAM e deploy em nuvem.

## Idiomas e Comunicação
- **Inglês (English):** Inglês técnico profissional para leitura, escrita de documentação em inglês, code reviews, especificações e comunicação internacional.
- **Português (Portuguese):** Nativo.
- **Comunicação Técnica (Communication):** Articulação clara de decisões técnicas e trade-offs através de RFCs, ADRs (Architecture Decision Records) e documentação técnica precisa.
- **Colaboração e Processos:** Code reviews rigorosos, pair programming, metodologias ágeis (Scrum, Kanban) e alinhamento com times de produto e negócio.
